# Alert Mesh Python prototype. Needs Python 3.10 or newer. Install (see README.md):
#   python3 -m pip install -r requirements.txt
# Each minimum is the lowest version this was tested with. The newest versions on
# 2026-09-27 were tested too (cryptography 50.0, plotly 7.1, pandas 3.0, streamlit 1.64,
# pytest 9.1, ipykernel 7.3, nbconvert 7.17).
cryptography>=46      # Ed25519 signing and verification (same curve as the Swift app)
plotly>=6.3           # maps and charts in the notebook and the Streamlit page
pandas>=2.3           # tables in the notebook
streamlit>=1.51,<1.65  # the pages; capped at the newest tested, as alertmesh/style.py styles Streamlit's own parts
pytest>=8.4           # tests that check the Python port against the Swift reference
ipykernel>=6.31       # lets VS Code run demo.ipynb
nbconvert>=7.16       # runs the notebook top to bottom as a check
bleak>=3.0            # phone app: finds nearby laptops over Bluetooth and sends to them
bless>=0.3,<0.4; sys_platform != "win32"  # phone app: lets nearby devices find this one and send to it (ble_mac reads its objects)
# On Windows the same is done with WinRT (alertmesh/ble_windows.py): bless 0.3 needs packages
# that are not on PyPI. These come with bleak; named here because the phone app uses them itself.
winrt-Windows.Devices.Bluetooth.GenericAttributeProfile>=3; sys_platform == "win32"
winrt-Windows.Storage.Streams>=3; sys_platform == "win32"
websockets>=16        # internet link: talks to Nostr relays, as the iPhone app does
pydeck>=0.9           # phone app: the map to drop a pin on (Streamlit draws it)
pyobjc-framework-CoreLocation>=12; sys_platform == "darwin"  # phone app: this Mac's own position
