Design spec · Phase 14 proposal · version 2

The iPhone app’s look, on a Mac or Windows desktop

Both desktop apps now borrow the iPhone app’s own style: the system typeface, system blue, 16-point rounded cards, a solid colour block only when a warning covers you, the red “I need help” bar, and Messages-style chat bubbles. The iPhone’s bottom tab bar becomes a sidebar, which is how Mac and Windows apps show the same three tabs.

Mac and Windows differences

The page is identical on both. Anything the system owns follows the system. The page learns which system it runs on from sys.platform.

Building it in Streamlit

Streamlit 1.51, as installed. The system typeface makes this simpler than version 1: no font files to bundle.

Proposed steps

One commit and one changelog entry each, as before. Nothing is built yet.

  1. 14.1

    iPhone palette, system typeface, dark mode

    Theme settings and one shared stylesheet with the Swift values, for both apps.

  2. 14.2

    Phone app sidebar and “I need help” bar

    Sidebar with Now, Report, Chat and badges; you and your town at its foot; status bar; the pinned red bar; window 1200 × 760, minimum 960 × 600.

  3. 14.3

    Now like the iPhone

    Solid status block only when a warning covers you, “What to do” card, calls for help, other warnings with colour bars, “How you’re connected”.

  4. 14.4

    Report and Chat like the iPhone

    Grey hazard reports and red calls for help; Messages-style bubbles; the call-for-help sheet with the system’s button order.

  5. 14.5

    Warning app in the same style

    Sidebar with Console, Map and Hub board; console in two columns with the phone preview; simulated clock at the foot.

  6. 14.6

    Keyboard shortcuts

    Tabs, Settings and “I need help”, with ⌘ or Ctrl shown to match the system.

  7. 14.7

    Check on Windows

    Build both apps on a Windows PC and look at 100%, 125% and 150% scaling. Left open until a Windows computer is available.
